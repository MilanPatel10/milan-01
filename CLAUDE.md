# Project Identity: Premium Web Design Node

## Tech Stack

- Framework: Next.js (App Router), TypeScript

- Styling: Tailwind CSS (Modern, fluid layouts)

- Motion: Framer Motion (Orchestrated spring reveals)

## Design Rules

- Typography: Custom display serif/sans pairs (No generic Inter or Roboto).

- Aesthetic: Glassmorphism, deep layered textures, asymmetrical grids.

- Animation: Staggered entry reveals, custom cubic-beziers. No jarring pops.
